# Support quality rubric v1

Version this file whenever judging criteria change. Tier 3 artifacts record the version so
scores from different rubrics are never compared as if they were the same measurement.

## Relevance (1-5)
Does the response address the user's actual problem rather than a generic adjacent topic?

- 5: Directly resolves the stated problem and anticipates the obvious next question.
- 3: Addresses the topic but omits a key part of the request.
- 1: Off topic or answers a different question.

## Coherence (1-5)
Is the response logically ordered and internally consistent?

- 5: Steps follow a sensible order with no contradictions.
- 3: Understandable but repetitive or loosely ordered.
- 1: Contradictory or hard to follow.

## Scope note
Tone, policy compliance, required disclosures, and formatting are checked deterministically in
Tier 1. Do not duplicate them here. A judge should only score what a rule cannot.
